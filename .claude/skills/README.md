# skills/

Project-specific skills for harkdle.

| Skill | Use it for |
| ----- | ---------- |
| [feature-dev](feature-dev/SKILL.md) | Interrogate → design → tasks → execute for any feature, bug fix, or design decision. Plans by default; executes on an explicit signal. Not for docs-only edits. |

`feature-dev` is stack-agnostic until the stack is chosen. Its
"Project profile" section in `SKILL.md` holds the stack, gate commands
and invariants; **fill it in the same commit that accepts the stack ADR**,
and keep it in sync with whatever mechanically enforces those invariants.
A skill that cites a rule nothing checks is worse than no skill.
